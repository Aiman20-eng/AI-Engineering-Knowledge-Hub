
# AI Engineering Knowledge Hub

**Research • Experimentation • Evaluation • Engineering**

A practical, evidence-based research hub for AI coding agents and AI-assisted software engineering.

## About

AI Engineering Knowledge Hub is an independent research project
focused on understanding, experimenting with, and evaluating
AI tools throughout the Software Development Life Cycle (SDLC).

It combines official documentation, hands-on experiments,
reproducible benchmarks, and engineering analysis.

## Research Areas

- Requirements Engineering
- Codebase Understanding
- Architecture Design
- Software Implementation
- Testing & Quality Assurance
- Code Review
- Security Engineering
- DevOps & CI/CD
- Multi-Agent Engineering
- Model Context Protocol (MCP)

## Initial Tool Research

- Claude Code
- OpenAI Codex
- GitHub Copilot
- Cursor
- Kiro

## Research Methodology

Every tool is studied using a consistent framework:

1. Official documentation analysis
2. Architecture and capability research
3. Hands-on experimentation
4. Reproducible evaluation
5. Evidence-based comparison
6. Limitations and lessons learned
